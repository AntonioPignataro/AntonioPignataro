Multi-tenant SaaS for youth clubs with 10+ modules: members, parents' portal, attendance,

### [Walkie — Push-to-Talk Voice App](https://github.com/AntonioPignataro/walkie)
Real-time push-to-talk for Android and iOS: direct and group voice rooms over WebRTC,
live connection requests and presence, and LiveKit tokens issued by a Supabase Edge Function,
so no secrets ship in the app. Personal project built with Claude Code (Flutter, LiveKit, Supabase).
